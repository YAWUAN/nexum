Jaringan **wireless** (nirkabel) mengirim data lewat gelombang radio tanpa kabel. Praktis dan fleksibel, tetapi rentan gangguan, interferensi, dan penyadapan. Bab ini membahas komponen, standar, keamanan, dan cara konfigurasinya.

## Komponen jaringan wireless

- **Wireless client** — perangkat yang terhubung (laptop, ponsel, tablet).
- **Access Point (AP)** — jembatan antara jaringan wireless dan kabel.
- **Wireless router** — AP + router + switch + DHCP dalam satu perangkat.
- **Wireless Controller (WLC)** — mengelola banyak AP terpusat (jaringan besar).
- **Antena** — memancarkan dan menerima sinyal.

## Standar Wi-Fi (IEEE 802.11)

| Standar | Frekuensi | Kecepatan maks | Catatan |
|---|---|---|---|
| 802.11b | 2.4 GHz | 11 Mbps | Lama |
| 802.11g | 2.4 GHz | 54 Mbps | Lama |
| 802.11n (Wi-Fi 4) | 2.4/5 GHz | 600 Mbps | MIMO |
| 802.11ac (Wi-Fi 5) | 5 GHz | 1.3 Gbps+ | Cepat |
| 802.11ax (Wi-Fi 6) | 2.4/5/6 GHz | 9.6 Gbps | Efisien di keramaian |

## 2.4 GHz vs 5 GHz

| Aspek | 2.4 GHz | 5 GHz |
|---|---|---|
| Jangkauan | Lebih jauh | Lebih pendek |
| Kecepatan | Lebih lambat | Lebih cepat |
| Gangguan | Banyak (microwave, Bluetooth) | Lebih sedikit |
| Kanal | 1-13 (hanya 1, 6, 11 yang tidak tumpang tindih) | Lebih banyak |

> **Poin penting:** Untuk kanal 2.4 GHz, pakai hanya **1, 6, atau 11** agar tidak saling tumpang tindih. Kanal lain akan menyebabkan interferensi antar-AP.

## Istilah penting

- **SSID** — nama jaringan Wi-Fi yang tampil di daftar perangkat.
- **BSSID** — alamat MAC dari AP.
- **ESSID** — SSID yang dipakai bersama oleh banyak AP (roaming).
- **Broadcast SSID** — apakah nama jaringan ditampilkan atau disembunyikan.

## Keamanan wireless

| Metode | Keamanan | Keterangan |
|---|---|---|
| Open | Tidak ada | Siapa pun bisa masuk |
| WEP | Sangat lemah | Sudah usang, mudah dipecah |
| WPA | Lemah | Pengganti WEP, masih ada celah |
| WPA2-Personal | Kuat | Pre-shared key + AES |
| WPA2-Enterprise | Sangat kuat | Per-user via server RADIUS |
| WPA3 | Paling kuat | Standar terbaru |

**WPA2-Personal** memakai satu **pre-shared key** (passphrase) untuk semua klien — cocok untuk rumah dan kantor kecil. **WPA2-Enterprise** memakai server **RADIUS** dengan username/password per pengguna — cocok untuk organisasi besar.

**Enkripsi:** pilih **AES** (bukan TKIP) untuk keamanan terbaik pada WPA2.

## Konfigurasi wireless router (Packet Tracer)

Pada perangkat Linksys/Wireless Router, buka tab **GUI**:

**1. Setup dasar (tab Setup → Basic Setup):**

- IP Address router: `192.168.0.1`
- Subnet Mask: `255.255.255.0`
- DHCP Server: **Enabled**
- Start IP Address: `192.168.0.100`
- Maximum Number of Users: sesuai kebutuhan

**2. Pengaturan wireless (tab Wireless → Basic Wireless Settings):**

- Network Mode: **Mixed** (mendukung 802.11b/g/n)
- Network Name (SSID): misal `SekolahNet`
- Standard Channel: **6 - 2.437GHz** (atau 1/11)
- SSID Broadcast: **Enabled**

**3. Keamanan (tab Wireless → Wireless Security):**

- Security Mode: **WPA2 Personal**
- Encryption: **AES**
- Passphrase: misal `Cisco123!`

Klik **Save Settings** setiap kali mengubah.

## Konfigurasi klien wireless

Pada laptop/tablet di Packet Tracer, buka tab **Config** → Wireless0:

- SSID: `SekolahNet` (harus **sama persis**)
- Authentication: **WPA2-PSK**
- Pass Phrase: `Cisco123!` (harus **sama persis**)
- IP Configuration: **DHCP**

> **Poin penting:** Klien hanya bisa terhubung kalau **SSID dan keamanan sama persis** dengan AP. Kesalahan paling umum saat lab wireless: salah ketik passphrase atau beda mode keamanan. Kalau SSID benar tapi IP tidak muncul, cek server DHCP.

## Wireless Controller (WLC)

Untuk jaringan besar, banyak AP ringan (lightweight AP) dikelola satu **WLC**:

1. Hubungkan WLC ke switch, AP ringan ke switch yang sama.
2. Beri **management interface** WLC alamat IP (biarkan **untagged**/native VLAN).
3. AP otomatis menemukan WLC dan mengunduh konfigurasi.
4. Di WLC, buat **WLAN**, petakan ke **VLAN/interface**, atur keamanan (WPA2-PSK atau WPA2-Enterprise).

**Peringatan:** management interface yang di-tag sering membuat AP gagal registrasi ke WLC.

## Tips keamanan wireless

- Ganti password default admin AP.
- Gunakan WPA2/WPA3, hindari WEP.
- Sembunyikan SSID bila perlu (bukan pengamanan utama).
- Aktifkan **MAC filtering** sebagai lapisan tambahan.
- Kurangi daya pancar agar tidak bocor ke luar area.
- Perbarui firmware AP secara berkala.

## Verifikasi

Di klien (tab Desktop → PC Wireless):

- Lihat status koneksi dan kekuatan sinyal.
- Ping gateway AP: `ping 192.168.0.1`.
- Ping klien lain untuk memastikan komunikasi.

## Latihan

1. Apa perbedaan 2.4 GHz dan 5 GHz?
2. Apa perbedaan WPA2-Personal dan WPA2-Enterprise?
3. Kanal 2.4 GHz mana yang sebaiknya dipakai agar tidak tumpang tindih?
4. Mengapa klien gagal terhubung walau SSID sudah benar?

**Kunci jawaban:**

1. 2.4 GHz jangkauan lebih jauh tapi lebih lambat dan banyak gangguan; 5 GHz lebih cepat dan bersih tapi jangkauan lebih pendek.
2. WPA2-Personal memakai satu pre-shared key untuk semua; WPA2-Enterprise memakai server RADIUS dengan kredensial per pengguna.
3. Kanal **1, 6, dan 11**.
4. Karena **passphrase atau mode keamanan tidak sama persis**, atau server **DHCP** tidak terjangkau sehingga klien tidak mendapat IP.
